This module integrates **[RTK](https://github.com/rtk-ai/rtk) — "Rust Token
Killer"** into OpenLumara.

- **Project:** rtk — a high-performance CLI proxy that filters and summarizes
  system command output to reduce LLM token consumption (60–90% on common dev
  commands). Single Rust binary, zero dependencies.

module only invokes it (via `rtk hook check`, `rtk recall`, `rtk gain`, and
rewritten shell commands). It ships no RTK source code or binaries. The
integration's instruction text is adapted from the `RTK.md` file generated by
`rtk init`, which is likewise part of the RTK project under Apache-2.0.
